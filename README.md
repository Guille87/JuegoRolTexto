# Rama `badges`

Rama huérfana (sin historia común con `main`) que solo contiene los badges
generados por el CI (`coverage.svg`). Está separada para que el CI pueda
actualizarlos sin pasar por un PR contra `main` (protegida).

El README apunta a:
`https://raw.githubusercontent.com/Guille87/JuegoRolTexto/badges/coverage.svg`
